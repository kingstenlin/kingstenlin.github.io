How to Use

  • Add singers via + Add Singer or import from Excel
  • Drag singers from the pool onto stage slots
  • Click an empty slot (or right click any slot) to search & place a singer, insert cells/rows, or mark it as an obstacle
  • Use the pool search bar and part filters to quickly find singers
  • Save your layout with Save / Load and restore it later
  • Print or export to PDF with the Print / PDF button
